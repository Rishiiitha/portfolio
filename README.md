# Rishitha V — Portfolio

A responsive, static portfolio built with HTML, CSS, and JavaScript.

The page includes a real portrait from `assets/`, LeetCode solve and contest stats, a GitHub contribution heatmap and public activity feed, and scroll reveal transitions. Live profile panels use public data and fall back to cached values when available.

## Run locally

Open `index.html` in a browser. The résumé is in `assets/`; the hero uses your GitHub profile avatar.

To preview with a local server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Deploy

This folder can be deployed as a static site to GitHub Pages, Netlify, or Vercel. No build step is required.
